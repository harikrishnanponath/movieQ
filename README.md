🎬 MovieQ - Movie Browser App 🎬

Welcome to MovieQ! 🎉 This is a sleek and intuitive movie browsing app that allows users to search and explore detailed movie information effortlessly. Built with modern Android development technologies, MovieQ provides a seamless experience while offering features like movie search, movie details, and smooth app navigation.
-------------------------------
🚀 Features

- Movie Search: Easily search for movies by name and explore their details.
- Movie Details: View comprehensive movie information such as ratings, release date, and description.
- Local Storage: Room Database for caching and storing movie data locally.
- Retrofit Integration: Fetch movie data from a third-party API using Retrofit for smooth and efficient data handling.
- Material Design: A clean and modern UI/UX following Material Design principles.
- RecyclerView: Optimized for displaying lists of movie data efficiently.
- Navigation Component: Smooth and intuitive navigation between different app screens.
- CardView & RatingBar: Customization for displaying movie details in a beautiful and user-friendly manner.
- Responsive UI: Flexible layouts using ConstraintLayout to support various screen sizes.
---------------------------
⚙️ Technologies Used
- Kotlin: The primary programming language for Android development.
- MVVM Architecture: A robust design pattern that separates UI, business logic, and data to improve maintainability.
- Room Database: For local storage and caching of movie data.
- Retrofit: For API integration and fetching movie data from external sources.
- Jetpack Libraries: To build a modern Android app with a focus on efficiency and user experience.
- Material Design: To ensure a clean and visually appealing UI/UX.
- Navigation Component: For better app navigation and flow management.
